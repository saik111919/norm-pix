Flutter API maps to its Compose equivalent (`showModalBottomSheet` -> `ModalBottomSheet`,
`DropdownMenu` -> `ExposedDropdownMenuBox`, `ScrollController` -> `NestedScrollConnection`).

## Phase 23 - Blur, not frosted: solid sheets over a page that blurs in step with them
- [x] On a phone the blur arrived after the sheet had opened. It was the window manager's blur behind the sheet's window (`FLAG_BLUR_BEHIND` + `blurBehindRadius`): every change is a request to the system server, applied a frame or more later, so the ramp trailed the sheet. Now the app blurs the page itself: the root draws the page through a `RenderEffect` blur whose radius is read every frame from where the sheet actually is (`AppOverlays.backdropBlur`, fed by `Modifier.blursBackdrop` on the sheet's content).
