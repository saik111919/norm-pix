## Added
- A loan can record its EMI by itself each month: turn on Record EMIs automatically on the loan's page
- Each EMI recorded that way is split into principal and interest from what you still owe
- A new loan records its EMIs each month from your default account, unless you turn it off
- What's new in the Feature guide (Settings > About): every new feature and where to find it
## Fixed
- Page titles (Notifications, Forecast, Bills calendar, a loan) now show as soon as the page opens
- A loan's EMI interest is no longer offered as a payment that looks like it repeats
